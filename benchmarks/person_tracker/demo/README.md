# ReID discrimination demo — contact sheet

`reid_discrimination_contact_sheet.png` demonstrates that the overhauled person
tracker's ReID embedding actually tells people apart on **real Tinker Orbbec
crops** — the capability the pre-overhaul *untrained random head* did not have
(it produced near-noise similarities).

Generated by `make_contact_sheet.py` using the **production** embedding path:
OSNet-AIN x1.0, **MSMT17-trained** weights (auto-discovered via
`scripts/fetch_reid_weights.sh`), fp16 forward — exactly what
`person_track_server` runs.

## What it shows (n = 8 real crops from 4 sessions)

- **Top row:** each crop labeled `session#idx`, annotated with its *self-flip*
  cosine — the crop vs its own horizontal flip, a **guaranteed same-identity**
  pair (same person, new viewpoint).
- **Matrix:** crop-vs-crop cosine similarity. The diagonal is self (1.00);
  off-diagonal is cross-crop (mostly different people).

Latest run:

| metric | value |
|---|---|
| same-identity (crop vs flip) mean | **0.983** |
| cross-crop mean | **0.448** |
| **separation** | **0.534** |

The `19:22#0 ↔ #1` pair scores ~0.79 — those two crops are the same operator
across one session, and the embedding correctly ranks them well above the ~0.4
cross-session pairs: same identity clusters high, different identities stay low.

For reference, the same demo on **imagenet-init** OSNet (no `reid_weights_path`)
separates 0.466; the MSMT17 weights widen it to 0.534.

## Caveat

This is an **embedding-discrimination** demonstration, not a benchmark *gate*
score. The ptbench arena gates (`wrong_lock_episodes`, `correct_lock_rate`,
`reacquire_latency`, …) require recorded Orbbec arena rosbags (Tier A), which do
not exist yet — see `../README.md` / `../PLAN.md`. The full ptbench unit suite
(200) and the vision_track unit/integration suite are green on this branch.
