Replace the in-memory waypoint lists with whatever the chosen yaml currently contains. Reload from draft picks up changes the auto-save mechanism wrote (e.g. a previous session). Quick actions

Grid corners

Jog to each grid corner to confirm the board stays in view from the current xArm pose. If it falls out of view at any corner, either adjust the xArm anchor in the Waypoints tab or tighten the grid in calibration.yaml.

Set zero-state (firmware wizard)

Persistent & irreversible from the UI. The current physical pose becomes the new firmware (pan, tilt) = (0, 0); every subsequent T:133 command is interpreted relative to it and any prior pan-tilt calibration becomes invalid.

  1. Jog the pan-tilt above to the physical pose you want to be the new zero.
  2. Unplug the cable from motor 2 (pan, X-axis).
  3. Send T:501 raw=1 new=2 (renumbers the still-attached servo).
  4. Reconnect the motor 2 cable.
  5. Send T:502 id=1 then T:502 id=2 (writes new zero into both servos).

Step 2 / 5. Physically disconnect the cable from motor 2 (pan / X-axis). Do NOT power-cycle the bus. Click continue only after the cable is unplugged.

Step 4 / 5. T:501 raw=1 new=2 sent. Now reconnect the motor 2 cable. Click continue once it's seated.
